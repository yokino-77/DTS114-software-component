# Screenshot Instructions

Please capture the following real screenshots manually. Do not add fake PNG files.

1. `commit_records.png`
   - Capture your GitHub commit history for this repository.
   - This should show the commit timeline and at least one meaningful commit message.

2. `website_deployment.png`
   - Capture the deployed website in a production or public deployment environment.
   - This should show the live website URL or hosting provider dashboard, not only localhost.

3. `cicd_workflow.png`
   - Capture the GitHub Actions workflow page showing a successful test run.
   - This should show the workflow name, run status, and passing job details.
