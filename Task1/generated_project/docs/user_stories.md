# User Stories

## User Story 1

**Story:** As a coach, I want to submit match statistics so that I can receive a concise performance report.

**Acceptance Criteria:** The system accepts valid match data and returns a structured analysis report.

## User Story 2

**Story:** As a match analyst, I want the system to identify tactical strengths and risks so that I can prepare notes for the coaching team.

**Acceptance Criteria:** The report includes strengths, risks, tactical observations, and recommendations.

## User Story 3

**Story:** As a system reviewer, I want a clear human review note so that I can verify the generated report before final use.

**Acceptance Criteria:** The system clearly states that the generated report requires human review.
